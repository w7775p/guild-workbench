# 公会工作台 v0.1

《公会今日照常营业》的本地优先内容工作台。v0.1 使用 APRD 与四个原案故事作为种子数据，支持人物、任务、中途事件、结果、条件与变化的可视化编辑，并提供引用检查、派遣预览、JSON 导入导出和 IndexedDB 草稿恢复。

## 运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

自动测试：

```bash
npm test
```

## v0.1 已实现

- 人物页：APRD 列表、分区表单、数组增删排序、任务／事件／结果引用定位。
- 故事页：四个故事的任务卡、事件选项、结果优先级、条件与变化构建器。
- 预览页：选择故事、APRD 队伍和事件选项，显示命中结果、逐条条件与变化；预览不写回项目。
- 问题页：阻断错误、内容警告、原案缺口分别显示，并可跳回字段。
- 项目操作：新建、载入内置原案、导入 JSON、导出 JSON、恢复浏览器草稿。
- 数据约束：JSON Schema + 业务引用校验；损坏导入不会替换当前项目，阻断错误会禁止导出。

## 原案边界

《无声的摇篮曲》《牧羊人的遗产》有完整事件与结果，可运行预览。《血液盛宴》只有一个事件与一个结果示例；《你掉的是这个左半边还是右半边》只有任务卡和事件概述。工作台将这些差异显示为 `sourceIssues`，没有补写缺失内容。

露娜、盖尔、泽克、葛林姆、莉亚等非 APRD 引用被保留为显式未解析引用。它们不会自动创建角色；相关限定选项在 APRD 预览中不会出现。

## 数据真源

正式可移植内容是导出的项目 JSON。IndexedDB 只承担当前浏览器的自动草稿，不是跨设备真源。所有页面编辑同一个 `GuildProject`；没有第二套可写数据。

数据结构见：

- `src/domain/`
- `src/data/project.schema.json`
- `src/data/guild-seed.v0.1.json`
- `docs/source-coverage.md`
