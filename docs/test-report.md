## 尚未验证

当前执行容器未安装 Chrome、Chromium 或 Firefox，因此没有进行真实浏览器的鼠标点击、截图和视觉溢出检查。关键界面交互已在 jsdom 中自动执行，但这不能替代最终人工浏览器验收。

首次打开交付版时仍需人工确认：

- 目标屏幕宽度下人物三栏和故事双栏没有遮挡；
- 浏览器下载权限允许导出 JSON；
- 清除站点数据后可用刚导出的 JSON 恢复；
- 长文本和多层条件在实际浏览器中的滚动、聚焦与换行正常。
